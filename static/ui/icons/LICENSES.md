# Иконки приложений рабочего стола

Наборы Iconify, по одному на стиль ОС (tools/build_icon_packs.py). Стиль tui рисует текстовые значки, glitched берёт набор aether.

- **aether**: Lucide (lucide), ISC, Lucide Contributors, https://github.com/lucide-icons/lucide
- **modern**: Fluent UI System Icons (fluent), MIT, Microsoft Corporation, https://github.com/microsoft/fluentui-system-icons
- **gnome**: Phosphor (ph), MIT, Phosphor Icons, https://github.com/phosphor-icons/core
- **classic**: Pixelarticons (pixelarticons), MIT, Gerrit Halfmann, https://github.com/halfmage/pixelarticons
- **phosphor**: Carbon (carbon), Apache 2.0, IBM, https://github.com/carbon-design-system/carbon/tree/main/packages/icons
- **workbench**: Tabler Icons (tabler), MIT, Paweł Kuna, https://github.com/tabler/tabler-icons
