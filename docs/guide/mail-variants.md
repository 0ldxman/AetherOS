# Почта: варианты ответа

Игрок пишет персонажам не что угодно: он выбирает вариант ответа и перепечатывает его текст. Варианты — **возможности** сценария,
их открывает нода «Возможность: Открыть» в графе (глава «[Сценарии](page:world-graph)»). Разговор складывается из обычных нод:
письмо персонажа («Персонаж: Отправить письмо»), за ним возможности ответа, а «Возможность: Использована» ведёт дальше.

## Персонаж

Раздел «Почта» в Студии: адреса персонажей. «+ Персонаж»: «Адрес» (`имя@машина`, строчными, уникален) и необязательное «Имя».
Карточка: «Адрес», «Имя в письмах», «Подпись», «Заметка автора». Адрес можно связать с персонажем мира (раздел «Персонажи») —
тогда варианты можно адресовать персонажу, а не адресу. Письмо на адрес, которого нет, возвращается от `MAILER-DAEMON`.

## Возможность: Открыть

| Поле | Что значит |
|---|---|
| Как | ответ на письмо · новое письмо · пересылка письма |
| Кому, Адрес | персонаж (любой его адрес) или конкретный адрес |
| В ответ на | письмо персонажа, на которое это ответ; пусто — ответ на любое его письмо |
| Что переслать | письмо, которое игрок пересылает (у пересылки) |
| Подпись в списке | текст кнопки у игрока |
| Текст для набора | что игрок перепечатывает (см. ниже); пусто — вариант уходит сразу, без набора |
| Приложить | ничего · этот объект · этот ключ · документ, подписанный ключом |
| Попыток | ноль — без ограничения |
| С учётки | вариант только для этой учётки (`логин@хост`); с другой — «???» или скрыт |
| Для кого | игроку хода · всем |
| Открыть | открытой · закрытой «???» |
| Когда недоступна | показать «???» · скрыть |
| Группа | верный ответ закрывает все возможности группы |

Во «Когда» идёт поток (открыть сейчас) или условие «да/нет» (открыта, пока условие верно у игрока, — так делают вариант, который
игрок видит с самого начала: «Да/нет» → «Когда»).

### Секрет и выбор

- `{{секрет}}`: игрок видит только длину и должен знать значение сам. Неверное значение — неверный ответ, попытка засчитана.
- `[[склад 7|склад 9]]`: игрок выбирает слово. «Возможность: Использована» с фильтром «Слово» ведёт каждое слово своей веткой.

Сверка не различает регистр, лишние пробелы и «е»/«ё». Если набран не тот текст, письмо не уходит и попытка не тратится.

## Чем кончилось

«Возможность: Использована»: **Верно** (текст и секрет совпали, вложение то; возможность и её группа закрываются), **Неверно**
(попытка засчитана), **Попытки кончились** (возможность закрыта). Выходы данных: возможность, набранный текст, выбранное слово,
сколько попыток осталось, письмо игрока в «отправленных» (размещение), учётка, игрок.

Письмо персонажу без варианта ждёт автора во входящих персонажа (лента кукловода) и ловится «Персонаж: Получил письмо».

## Пример: охрана порта

В демо-мире сценарий «Dock access»:

1. «Да/нет» → «Когда» у «Возможность: Открыть» (новое письмо `guard@aether-core`, «Ask for dock access») — вариант виден всем.
2. «Использована → Верно» → письмо `guard-ask` → «Открыть» ответ «Give the password» (`Password: {{hunter2}}. Dock [[7|9]], please.`, 3 попытки, группа `ask`).
   Рядом «Mention the tunnel» той же группы: во «Когда» — «Факт» `tag:tunnel`, без тега вариант показан «???».
3. «Использована» со словом `7` → письмо `guard-open` и тег `dock-open`; со словом `9` → письмо про ремонт и снова «Открыть» пароль;
   «Неверно» → `guard-wrong`, «Попытки кончились» → `guard-closed`.
