# Файлы, защита и ключи

## Что такое файл для игрока

Файл это то, что лежит на диске машины. Формат файла (текст, документ, письмо, архив, ключ, приложение) определяется базой, а не расширением.
Игрок открывает файл двойным щелчком на столе или командой `cnt`, и открывается подходящий просмотрщик: текст, документ, письмо в почте,
картинка, звук, видео, карта, список архива.

Править игрок может текстовые файлы своей машины командой `edt`. Правка записывается в его личную копию, оригинал у других игроков остаётся прежним.
Письма, ключи, архивы и картинки редактору не открываются.

Скрытые файлы (имя с точки) показывает `ls -a`.

## Корзина

`del` отправляет файл в корзину `~/.trash` и спрашивает подтверждение. Через семь дней корзина очищается сама.
`rcvr` возвращает файл, но он возвращается **повреждённым**: чем дольше пролежал, тем сильнее (до пяти слоёв), и его придётся чинить `rpr`.
На удаление и восстановление автор может повесить свои реакции, например, письмо-предупреждение.

## Слои защиты

Файл может быть закрыт одним или несколькими слоями. Пока слой не снят, файл не прочитать:
`cnt` отвечает `content is locked`, на столе значок серый, в почте письмо показывает только заголовки.
Снимает слои игрок командами, причём сверху вниз: сначала верхний.

| Слой | Как выглядит | Что делать |
|---|---|---|
| повреждён (`damaged`) | файл «битый» | `rpr файл` |
| зашифрован (`encrypted`) | нужен пароль и/или ключ | `ward файл пароль` или `ward -k ключ файл` |
| сдвинут (`shifted`) | сначала шум, потом данные | `blk файл skip=N`: найти, с какого блока идёт настоящее |
| бинарный (`binary`) | нечитаемая кодировка | `cvt enc кодировка файл` |
| замаскирован (`disguised`) | на самом деле другой формат | `cvt ext файл выход.расширение` |
| повреждён навсегда (`corrupted`) | только описание | ничего не сделать |

Если на файле не тот слой, который пытается снять команда, попытка не засчитывается.

### Попытки

У зашифрованного файла обычно три попытки. Неверный пароль отвечает `ward: decryption failed: Bad session key`, неверный ключ `No secret key`.
Когда попытки кончаются, **блокировки нет**: автор может повесить на этот момент любую реакцию (повредить файл, удалить его, отправить письмо,
вышвырнуть игрока, показать окна с ошибками), но слой всё равно можно снять потом правильным паролем.
Сколько попыток осталось, игрок узнаёт только если автор написал это в тексте реакции.

## Архивы

Архив это файл с вложенными файлами, расширение у него любое (`.zip`, `.7z`, `.pak`). `pak l` показывает состав и размеры,
`pak x` распаковывает в папку рядом с архивом. Защищённый архив отвечает `password required` (нужен `pak pass архив пароль`)
или `Unexpected EOF in archive` (повреждён). Внутри архива может лежать другой архив.

## Ключи

**Ключ** это особый файл. У него есть имя (идентификатор), и на это имя в мире ссылаются условия: «это приложение видно, только если есть ключ `alpha`»,
«эта страница вики показывается с ключом `harbor-pass`», «этот ответ в письме доступен с ключом такого-то».

Ключи не выдаются автоматически. Их надо **найти**:

1. Автор прячет блок ключа внутри байтов обычного файла (в картинке, документе, архиве). Блок начинается с `-----BEGIN ACCESS KEY-----`
   и содержит строку `Keyname: <имя>`.
2. Игрок находит его: `txtx файл` печатает читаемые строки со смещениями, `cnt -r файл` показывает файл в «сыром» виде.
3. `kex файл смещение` забирает ключ. Смещение можно писать десятичным или с `0x`. Ответ: `kex: файл: key имя extracted to …`,
   или `no key at 0xNN`, если там ничего нет.
4. Если файл зашифрован, в его байтах шум. Сначала снимите слой, потом ищите ключ.

Ключ лежит файлом в `~/.secrets`. `ward keys` показывает список (`ID`, имя, файл, заметка). Если удалить файл или отключить диск, где он лежал, ключ пропадёт.

Ключи бывают и наградой: письмо персонажа может положить ключ в папку секретов.

### Для чего ключи

- **Расшифровать** файл (`ward -k`).
- **Войти** на машину (`rcon -i ключ`, `rshell`, `xfer`, `mnt`), если учётка так настроена.
- **Подписать** файл (`ward sign -k`) и **проверить подпись** (`ward verify`). Подпись может оказаться подделкой.
- **Открыть** то, что закрыто условием на ключ: приложения на столе, страницы вики, участки карты, закрытые ответы в письмах,
  узлы и страницы сети (`nreq`, `nget`), части документов под `::spoiler`.

Закрытое условием на ключ игрок часто не видит вовсе: ни приложения, ни страницы, ни ответа. Пока у него нет ключа, этого «не существует».
