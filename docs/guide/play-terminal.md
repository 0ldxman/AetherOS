# Терминал

Терминал (`console.sh`) это главный инструмент игрока. Через него он смотрит файлы, ищет скрытое, снимает защиту, достаёт ключи и ходит на другие машины.

![Работа в терминале](clip:player-terminal)

## Как он выглядит

Приглашение: `login@hostname:path$`. Домашняя папка показывается как `~`. При открытии окна проигрывается короткое приветствие
с названием системы, логином и числом новых писем.

- Введённая команда подсвечивается цветом акцента, ответ с ошибкой красным.
- Многие команды перед ответом показывают короткую анимацию: полоски прогресса и строки `[ OK ]` и `[FAIL]`.
- Стрелки вверх и вниз листают историю команд. История живёт, пока открыто окно терминала.
- `Esc` или `Ctrl+C` отменяют запрос пароля или подтверждения.
- Автодополнения по `Tab` нет.
- Каналов и перенаправлений (`|`, `>`, `&&`, `;`) нет: такая строка отвечает `Shell operators are not supported`.
- Кавычки работают: имя файла с пробелом заключают в них.

Если подключений несколько, сверху видны вкладки по одной на каждое. Щелчок по вкладке переносит туда терминал, а правая кнопка предлагает
перенести туда и стол или закрыть соединение.

## Справка

`help` показывает команды по группам, `help <команда>` её синтаксис. Неизвестная команда отвечает `<имя>: command not found`.

## Команды

### Файлы

| Команда | Что делает |
|---|---|
| `pwd` | где я |
| `ls [-a] [-l] [-h] [путь]` | список файлов; `-a` показывает скрытые (начинаются с точки), `-l` права, владельца и размер |
| `cd [путь]` | перейти; без аргумента домой |
| `cnt файл` | открыть в подходящем просмотрщике; `cnt -r файл` в «сыром» виде: байты и текст |
| `edt файл` | открыть редактор |
| `cp [-r] откуда куда`, `mv откуда куда` | копировать и переносить; никогда не затирают существующее |
| `del [-f] [-r] файл` | отправить в корзину (спросит `y/n`; подходят `y`, `yes`, `д`, `да`) |
| `rcvr файл [куда]` | вернуть из корзины |
| `wipe [-f]` | очистить корзину |
| `perm ddd файл` | права тремя восьмеричными цифрами |
| `own владелец[:группа] файл` | сменить владельца (нужна привилегия) |
| `clear` | очистить экран |

### Разобраться в файле

| Команда | Что делает |
|---|---|
| `ftyp файл` | определить тип по содержимому |
| `txtx файл` | найти в файле читаемые строки и показать их смещения: `0xСМЕЩЕНИЕ  текст` |
| `blk файл skip=N` | вырезать блок (блок равен 512 байт); нужен, когда нужные данные сдвинуты |
| `cvt enc кодировка файл` | прочитать файл в другой кодировке (`utf16`, `cp1251`, `rot13`, `base64`, `gzip`, `morse`, `hex`) |
| `cvt ext файл выход` | прочитать файл как другой формат |
| `rpr файл` | починить повреждённый файл |

### Ключи, пароли, архивы

| Команда | Что делает |
|---|---|
| `kex файл смещение` | достать ключ, спрятанный в файле по этому смещению |
| `ward файл пароль` | расшифровать файл паролем |
| `ward -k ключ файл` | расшифровать файлом-ключом |
| `ward keys` | список ключей игрока |
| `ward sign -k ключ файл`, `ward verify файл` | подписать файл и проверить подпись |
| `pak l архив` | показать содержимое архива |
| `pak x архив [файлы] [-d папка]` | распаковать |
| `pak pass архив пароль` | снять пароль с архива |

Подробно: [файлы, защита и ключи](page:play-files).

### Сеть

| Команда | Что делает |
|---|---|
| `nreq [--token t] адрес[/путь]` | прочитать страницу ресурса |
| `nget [--token t] [-o путь] адрес/путь/файл` | скачать файл |
| `rcon [-p частота] [-i ключ] [--token t] логин@хост` | подключиться к другой машине, стол переезжает туда |
| `rshell` | то же, но стол остаётся на месте |
| `xfer` | копировать между машинами внутри `rshell` |
| `mnt`, `umnt` | подключать и отключать сетевые диски |
| `exit`, `rcon-close` | выйти из текущего подключения или из всех |

Подробно: [другие машины](page:play-remote).

### Время и прочее

`date` показывает время на этой машине. У каждой машины своё время для каждого игрока. `tmset +3h`, `tmset -1d`
или `tmset 2031-05-01 12:00` переводят его, `tmset reset` возвращает назад. Для этого нужна привилегия «часы», у обычного игрока её может не быть.

## Какие ответы встречаются

| Ответ | Значит |
|---|---|
| `Permission denied` | у учётки нет прав на этот файл |
| `Operation not permitted` | действие запрещено вообще |
| `content is locked` | на файле ещё есть защитные слои, [их надо снять](page:play-files) |
| `No such file or directory` | такого нет (или он скрыт от этой учётки) |
| `no display: the desktop is on another machine` | `cnt` и `edt` открывают окна на столе, а стол на другой машине |

Права у учётки зависят от групп и привилегий. Если команда не работает у игрока, возможно, автор не дал привилегию намеренно.
