# Поддержка игроков

Игрок пишет обращение из приложения `support`. В Студии раздел «Поддержка» это очередь обращений и переписка.

![Поддержка в Студии](shot:studio-support)

## Очередь

Слева вкладки: «Открытые» (все, кроме закрытых; по умолчанию), «Новые», «Мои» (назначенные вам, не закрытые), «Закрытые», «Все». Не больше 300 строк, обновляется каждые 20 секунд.
В строке: тема, точка «Последнее слово за игроком» (ждёт команду), статус, игрок, давность, «исполнитель: …».

Статусы:

| Статус | Значит |
|---|---|
| «Новое» | никто не ответил |
| «В работе» | взято или игрок ответил |
| «Ждёт игрока» | команда ответила |
| «Закрыто» | завершено |

Правила переходов: ответ игрока возвращает обращение «В работе», в том числе закрытое. Ответ команды ставит «Ждёт игрока» и назначает ответившего исполнителем, если исполнителя ещё нет.
Назначение исполнителя на «Новое» переводит его «В работе». Внутренняя заметка статус не меняет. Закрывается обращение вручную через список «Статус».

## Карточка

Слева лента сообщений: сообщения игрока, ответы команды (подписаны «как <имя>») и внутренние заметки с тегом «заметка команды».
Картинки показываются миниатюрами и увеличиваются по щелчку, остальные файлы это ссылки с названием и размером.

**Ответ.** Поле «Ответ игроку от имени <имя> (по-английски)», `Ctrl+Enter` отправляет, «Приложить файлы» (до пяти по 5 МБ), «Ответить».
Галочка «Заметка команды» превращает сообщение во внутреннюю, которую игрок не увидит, и кнопка меняется на «Добавить заметку».

**Справа:**

- «Статус» и «Исполнитель» (из тех, у кого есть право на раздел «Поддержка»), кнопка «Взять себе».
- **«Кто отвечает игроку»** (до 60 знаков, по умолчанию `AETHER AGENT`): имя, которым подписаны **все** ответы в этом обращении. Для игрока это ИИ узла, а не человек.
  Имя меняется сразу для всей переписки.
- «Игрок»: ссылка на его профиль.
- «Где был, когда писал»: машина, учётка и браузер (со ссылками на машину и учётку).

## Уведомления

Команда получает уведомление о каждом новом обращении и о каждом новом сообщении игрока (ссылка ведёт в карточку). Получают все авторы с правом на «Поддержку»,
а если обращение назначено, то только исполнитель. Кроме того, на [главной](page:team-dashboard) есть блок «Поддержка» с очередью.

Права на раздел настраиваются в ролях: [роли и права](page:team-roles).
