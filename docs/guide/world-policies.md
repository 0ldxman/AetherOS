# Политики входа

Политика входа говорит, **когда, откуда и как часто** можно входить на машину. Что именно нужно предъявить (пароль, ключ, токен), по-прежнему определяет учётка.

![Политики входа](shot:studio-policies)

## Где назначается

Самая точная политика главнее: **учётка**, затем **машина**, затем **тип системы**. Без политики войти можно откуда угодно и когда угодно, нужны только пароль и ключи учётки.
В списке политик у каждой показано, где она используется («ОС X · машин N · учёток M» или «не назначена»). Политику, которая где-то назначена, удалить нельзя.

## Поля

| Блок | Поле | Что значит |
|---|---|---|
| Кто и откуда | «Пароль и ключ» | «нужны и пароль, и ключ» или «хватает пароля или ключа»; токен пускает мимо обоих |
| | «Откуда можно» | хосты по одному в строке, `*` как шаблон (`aether-*`); пусто: откуда угодно |
| | «Только через» | хосты, через которые должна пройти цепочка мостов |
| Ошибки и срок | «Ошибок до блока» | пусто: блокировки нет |
| | «За сколько секунд» | окно подсчёта ошибок (по умолчанию 600) |
| | «Блок на сколько секунд» | по умолчанию 300; действует и после обрыва по сроку |
| | «Срок подключения, секунд» | пусто: без ограничения |
| Когда | «Окна» | по правилу в строке: `mon-fri: 9:00-13:00 14:00-18:00`, `except sun: *` |
| Что видит игрок | «Отказ», «Блокировка», «Вне окна», «Обрыв по сроку» | свои тексты; пусто: стандартные для системы |

Дни в окнах: `mon`…`sun`. Рядом показывается недельная сетка и ошибка разбора, если правило записано неверно.

Поля учётки «Срок подключения», «Блок после обрыва» и «Сообщение при обрыве» главнее политики. Проверить итог можно на вкладке «Проверка входа» машины.

## Что видит игрок

Игрок никогда не узнаёт, какое именно условие не выполнено: при отказе он видит только `Permission denied (publickey,password).` со списком методов этой учётки.
После нескольких ошибок: `account locked, security review in progress (retry in MM:SS)`.
