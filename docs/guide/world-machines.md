# Машины и учётки

Раздел «Машины» показывает хосты мира: учётки, доступ, кто сейчас на них и что там происходило.

![Список машин](shot:studio-machines)

## Список

Столбцы: «Хост», «ОС», «Статус», «Учёток», «Сейчас» (игроков на машине), «Отказов за сутки», «Последний вход», «Замечания».
Есть фильтр по статусу («в сети», «не в сети», «обслуживание»), кнопка «⚠ С замечаниями» и поиск по хосту, названию и ОС.

## Новая машина

Кнопка «Новая машина». Поля: «Хост» (имя для подключения, например `gw-07`), «Название», «ОС», «Статус».
Корень машины берётся одним из четырёх способов:

- **Свой диск по шаблону**: пустая структура папок, диск создаётся только для этой машины.
- **Общий образ**: готовый диск, который видят все машины, где он смонтирован.
- **По образцу машины**: копия учёток, групп, путей, экспортов и дисков другой машины (личные диски копируются).
- **Пустая**: корень появится при первой записи.

Новую машину по образцу можно создать и кнопкой на вкладке «Обзор» существующей.

## Вкладки машины

«Обзор», «Учётки», «Проверка входа», «Журнал», «Группы», «Файлы», «Диски». Адрес вкладки можно отправить коллеге: `#/машины/id/вкладка`.

### Обзор

- **Основное:** «Хост», «Название», «ОС», «Статус», «Политика входа машины» (от ОС или своя).
  Политика самой учётки главнее, итоговую показывает вкладка «Проверка входа».
- **Идентичность** (по умолчанию выводится из `hid`): `hid`, адрес (частота МГц или сетевой), серийный номер, ключ узла. Одинаковый `hid` у двух машин делает их клонами.
  Кнопки «Сгенерировать» создают значения, у ключа узла рисуется отпечаток.
- **Для приветствия ОС:** «Включена с» (в приветствии `{uptime}`) и «Заметка» (`{note}`). Заметка хорошее место для подсказки игроку.
- **Справа:** сколько игроков на машине. У каждого кнопки «Разблокировать» и «Выкинуть» (выброс действует при следующем действии игрока). Ниже «Последние события» и ссылка на журнал.
- **Предупреждения** сверху:
  - «У учётки … нет ни пароля, ни ключа: войти может любой.» (для общих учёток);
  - «У учётки … группы, которых нет на машине: …»;
  - «У машины нет имени хоста: к ней нельзя подключиться по имени.»
- **Удалить машину** убирает учётки, сессии, журнал, монтирования, экспорты и её группы. **Диски остаются**, лишние надо удалить в «Диски и файлы». Системные машины не удаляются.

### Учётки

![Учётки машины](shot:studio-accounts)

Слева список: «Учётки автора» и свёрнутые «Рабочие учётки игроков». Значки показывают `root`, пароль, ключ и «открыта» (ни пароля, ни ключа).
Кнопка «+ Учётка» предлагает два вида:

- **общая**: для загадок, в неё входят любые игроки;
- **для игрока**: станет его рабочей учёткой. У игрока на машине может быть только одна рабочая учётка.

Форма учётки:

| Раздел | Поля |
|---|---|
| Кто это | «Логин», «Частота / порт», «Имя», «Почта» (пусто: `логин@метка`), «Игрок» (отдать или отвязать) |
| Группы и права | группы машины значками, галочка `root: все привилегии и обход прав файлов` |
| Как войти (только общие) | «Пароль», «Ключи» (выражение `a and (b or not c)`), «Политика входа» |
| Подключение | «Срок подключения, секунд», «Блок после обрыва, секунд», «Сообщение при обрыве», «Сцена после входа» |
| Токены | «+ Токен»: сколько раз можно войти, до какого срока |

Правила:

- Пароль, ключи, политика и токены **не применяются** к рабочей учётке игрока: она создана при входе и для неё доступа не проверяют.
- Токен показывается один раз («Новый токен: …»). Он пускает игрока мимо пароля и ключей.
  Список показывает «использован N из M» и «бессрочный», кнопка «Отозвать» гасит токен.
- Срок подключения и блок после обрыва, если заполнены, главнее политики входа. Пусто значит «из политики».
- Ниже список игроков на этой учётке: онлайн ли, блок, число отказов за неделю, «Разблокировать» и «Выкинуть».
- Учётку игрока удалить нельзя.

### Проверка входа

**«Открыть песочницу»** запускает [песочницу](page:team-sandbox) с подсказкой команды для этой учётки (`rcon логин@хост`): вход набирается руками в настоящем терминале, работают политика, пароль, блокировки и обрывы.

Ниже сухой прогон: проверяет, пустит ли учётка при заданных условиях, и ничего не записывает (ни событий, ни расхода токена, ни блокировки).
Слева итоговая политика учётки и откуда она взялась («своя у учётки», «от машины», «от типа системы»), справа форма: «Откуда (хост)», «Цепочка мостов»,
«Время на машине», «Игрок», «проверить пароль», «Ключи», «Токен». Вердикты: «Пустит», «Не пустит» и «Правила пропускают, остались пароль или ключи»,
со списком шагов с галочками и крестиками.

### Журнал

Все события входа: вход, неверный пароль, нет ключа, токен отвергнут, не с того хоста, не через тот хост, вне окна времени, блокировка,
разблокирован автором, выкинут автором. Фильтры по учётке, типу, игроку и периоду. Есть время на часах машины.

### Группы и привилегии

Права у учётки складываются по её группам, `root` имеет всё. Матрица: строки группы, столбцы привилегии.

| Привилегия | Что даёт |
|---|---|
| `clock` | менять время машины (`tmset`) |
| `backup` | читать любые файлы мимо прав |
| `restore` | писать в любые файлы мимо прав |
| `chown` | менять владельца файлов |
| `mount` | подключать диски (`mnt`) |
| `bridge` | открывать мосты на другие машины (`rcon`, `rshell`) |
| `transfer` | передавать файлы (`xfer`, `nget`) |

Если ни система, ни машина не задают групп, действует группа `users` с `bridge` и `transfer` для всех.
Щелчок по ячейке группы ОС переопределяет её только на этой машине (значки «переопределена», «своя», «от типа», «по умолчанию», «отключена»).
Кнопки: «Как у типа», «Отключить», «Удалить», «+ Группа машины» (имя латиницей). Правки применяются сразу, кнопки «Сохранить» нет.
Группы всей ОС правятся в разделе [операционных систем](page:world-systems).
