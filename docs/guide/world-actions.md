# Действия

Всё, что мир делает в ответ игроку, описывается действиями из одного словаря:
- исходы вариантов в почте;
- исходы ответчиков в эфире;
- триггеры на пульте «Состояние мира»;
- действия персонажа при отправке ответа.

Редактор везде один и тот же: «+ действие», выбор из списка, поля под выбранное действие. Место показывает только те действия, которые в нём имеют смысл.

## Что есть

| Группа | Действие | Что делает |
|---|---|---|
| Игрок | «Поставить метку игрока», «Снять метку игрока» | личная метка; по ней работают «Нужны метки» и «Мешают метки» в почте |
| Игрок | «Выдать ключ» | кладёт ключ в папку секретов учётки |
| Игрок | «Положить файл» | объект по слагу на путь машины, например `/home/{login}/file.txt` |
| Игрок | «Прислать письмо» | письмо в ящик учётки, можно с задержкой в секундах |
| Браузер | «Засыпать окнами ошибок» | окна ошибки с сообщением из каталога системы: сколько окон, пауза между ними |
| Браузер | «Открыть окно» | окно по внутреннему адресу, например `apps/wiki/go/secret/` |
| Браузер | «Выбросить из сессии» | игрока выбрасывает с учётки при следующем запросе |
| Мир | «Поставить метку мира», «Снять метку мира» | `world:имя`, одна на всех |
| Мир | «Вклад в счётчик мира» | прибавить к счётчику |
| Мир | «Опубликовать новость» | новость в ленте, важная всплывает на столе |
| Мир | «Передать в эфир» | станция говорит на частоте, можно шифром |
| Мир | «Письмо всем» | письмо каждому игроку при открытии почты |
| Мир | «Запись на форуме» | новая тема или запись в тему (см. «Форум») |
| Переписка | «Перейти на шаг», «Вернуть как недоставленное» | только в почте |

## Где что доступно

| Место | Действия |
|---|---|
| Исход варианта в почте | все |
| Исход ответчика в эфире | все, кроме переписки |
| Триггер мира | только мир: у триггера нет игрока |
| Ответ персонажа и «Написать первым» | мир и метки игрока |

Если действие не может выполниться (нет ключа, раздела, станции), остальные действия списка всё равно выполняются, а причина пишется в журнал мира на пульте «Состояние мира».
