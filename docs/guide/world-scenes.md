# Сцены: язык консольных анимаций

Сцена это текст, который игрок видит как консольную анимацию: загрузку машины, подключение, отказ, обрыв. Игрок в них только смотрит.
Сценами мира управляют слоты операционных систем ([операционные системы](page:world-systems)).

![Редактор сцены](shot:studio-scenes)

## Экран «Сцены»

Список слева и «+ Сцена» (идентификатор латиницей и название). В редакторе: заголовок, слаг, «▶ Играть», «Удалить», «Сохранить».
Выпадающий список «Подстановки события» показывает параметры выбранного слота, их значки вставляют `{имя}` в текст.
Ошибки пишутся как «Строка N: …». Блок «Где играет» перечисляет, куда сцена назначена. Свёрнутая «Шпаргалка по языку сцен» напоминает синтаксис.

Назначается сцена в «Операционные системы» → «Сцены событий».
Если сцена не компилируется, у игрока играет встроенная.

## Язык

Каждая строка это либо вывод, либо шаг со знаком `@`.

| Запись | Что делает |
|---|---|
| `# текст` | комментарий. Чтобы вывести строку с `#`, напишите `\#` |
| строка без значка | вывод на экран (с разметкой как в приветствии ОС и `{подстановками}`) |
| `~ текст` | тусклая строка. Для строки, начинающейся с `@` или `~`: `\@`, `\~` |

Тэги внутри строки:

| Тэг | Что делает |
|---|---|
| `<count to=64000 unit=K ms=600-1100/>` | число бежит вверх до значения |
| `<type speed=22 human typo chunk=3>…</type>` | печать по буквам, `human` живее, `typo` с опечатками |
| `<mark имя>…</mark>` | пометить кусок, чтобы потом заменить глитчем |
| `<cursor/>` | мигающий курсор |

Одиночные `<`, `>`, `{`, `}` в тексте надо экранировать: `&lt;`, `&gt;`, `{{`, `}}`. Строка начинается с `>` как знак: пишите `$ ` или `&gt;`.

Шаги (части через `|`):

- `@blank [n]`, `@clear`, `@cut`, `@flash`: пустые строки, очистка, обрыв, вспышка
- `@wait мс`, `@read`: пауза, пауза на чтение
- `@task метка | результат | мс`: строка задачи вида `метка ….. OK`
- `@unit имя | описание | результат | мс`: юнит-строка загрузки
- `@bar метка | мс`: полоса прогресса
- `@count метка | до | единица | мс`: счёт
- `@log сек | тег | сообщение`: строка журнала с отметкой времени
- `@glitch имя | новый текст`: исказить помеченный кусок
- `@countdown Старт через {n}с... | 5`: обратный отсчёт
- `@include слаг`: вставить другую сцену (вложенность до 8)

Блоки (строки блока начинаются с пробела): `@rows width=12`, `@bars width=14`, `@burst gap=8-45`.
Время пишут числом (`450`) или диапазоном (`200-450`): диапазон выбирается заново при каждом показе.

Подстановки `{имя}` зависят от слота. Неизвестная подстановка это ошибка при сохранении.

## Примеры

Загрузка:

```
# загрузка
@task Проверка памяти | OK | 200-450
@unit net | сетевой стек | up | 300
@bar Загрузка ядра | 1200
```

Приветствие с подстановками:

```
<success>Вход выполнен</success>
Добро пожаловать, {login}@{host}
Последний вход: {last_login}
<dim>Открыто <rand>21-41</rand> соединений</dim>
```

Печать и счёт:

```
$ <type human typo>scan --all</type>
Найдено: <count to=64000 unit=K ms=600-1100/>
@wait 500-900
```

Глитч и отсчёт:

```
<mark ip>192.168.0.7</mark>
@glitch ip | ??.??.??.??
@countdown Старт через {n}с... | 5
```

Все четыре примера проверены компилятором сцен без ошибок.
