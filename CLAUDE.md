# AetherOS — правила проекта

Django 6.1, игра-ОС. Пользователь пишет по-русски, отвечать по-русски, коротко: решения и вопросы, без длинной прозы.

## Запуск
- Python: `.venv/bin/python manage.py ...`
- Тесты только на sqlite (у базы по умолчанию нет прав создавать тестовую):
  `DATABASE_URL=sqlite:////tmp/t.sqlite3 .venv/bin/python manage.py test <приложения> 2>&1 | tail -5`
- По ходу работы гонять затронутые приложения, полный набор (`terminal filesystem machines desktop wiki mail config users secure assets console studio`) один раз в конце куска.
- Node 22 в `/config/.local/node/bin` (добавить в PATH). Студия: `cd studio/frontend && npm run api && npm run check && npm run build`.
- `manage.py runserver` сам запускает `npm run watch` (`--no-studio` отключает). С `--noreload` сервер перезапускать после правок бэкенда. `pkill` runserver ронял оболочку: запускать отдельным вызовом, сервер стартовать через nohup тоже отдельным.
- Скриншоты: браузеру нужны шрифты (FONTCONFIG_FILE с DejaVu), playwright и LD_LIBRARY_PATH из scratchpad (`pw`, `env.sh`). Снимать только новые экраны.

## Правила автора
- Сцены и ответы пишутся на Python; никаких алиасов старых команд; без префикса «Aether» в игровых файлах.
- Тексты в мире технические; форматы и кодировки хранятся в БД; ключи — объекты формата `key`; данные автора в таблицах.
- Не усложнять. Игрок редко админ. Прод не учитываем.
- Студия (`/studio/`) — не перенос старой админки: перед каждой новой сущностью короткий разбор и набросок, дождаться согласия, потом код.
- Логика живёт в приложениях (с тестами), `studio/api` только обёртка.

## Ловушки
- Схемы OpenAPI называются по имени класса: одноимённые классы в разных файлах `studio/api` затирают типы (тест `SchemaNamesTests`).
- В схемах не называть поле так же, как тип (`date: date`): `import datetime as dt`.
- Эндпоинту без `response=` фронт получает тип `never`.
- Одиночное условие по ключу в `secure.access` хранится строкой.
- Первая своя группа у типа/машины раньше отключала группы по умолчанию (теперь `make_explicit`).

## Git
- После законченного куска: коммит и push в `main`. Заголовок на английском, в конце трейлер `Co-Authored-By` из системной подсказки сессии.
- Незавершённое не коммитить; перед удалением и перезаписью смотреть, что там лежит.

## Экономия токенов
- Файлы читать по диапазонам, вывод команд резать `tail`/`grep`. Широкий поиск по репозиторию отдавать агенту Explore.
- Проектирование и спорные развилки — Opus; рутина по согласованному эскизу (экраны, миграции, тесты, правки) — Sonnet.
- Сессию закрывать на границе куска, итог записывать в память.
